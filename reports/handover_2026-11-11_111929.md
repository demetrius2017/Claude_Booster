# Handover 2026-11-11: unattended sessions no longer wait for the owner

## Summary

The owner reported that Desktop sessions in bypass mode still stopped on a question overnight. In the morning the task was not done, and `/goal` and `/loop` did not help. Transcript evidence: the ETIM Desktop sessions (bypassPermissions) stopped on AskUserQuestion on 2026-11-11 at 01:22Z and were answered only at 09:15Z and 09:02Z (7.9h and 7.7h). horizon had stops of 10.0h, 5.1h, 4.7h and 3.3h. While a dialog is open the turn cannot end, so Stop-based `/goal` and `/loop` never run.

Root causes, verified in code:
1. `fable_autopilot.py` is per-project opt-in. The stalled projects had no `autopilot.json`, so the hook was silent.
2. When it was enabled, it never called an advisor itself, had a 3-call cap, and its broad USER_ONLY regexes sent questions back to the owner.
3. The only enabled install (electro-estimate-ai) was permanently `degraded`: the trusted runner's PATH did not include `~/.local/bin` (exit 69).
4. Nothing intercepted ExitPlanMode.

**Delivered** in commit `ffd79b3` on branch `feat/unattended-question-router`, pushed to origin, **not merged and no PR**. Installed in `~/.claude` (parity checked).

- New hook `templates/scripts/question_router.py` (PreToolUse/PermissionRequest/Stop, timeout 300s). It is active in `bypassPermissions`, `dontAsk` and `auto`; this was the owner's choice in this session.
- Questions go to the advisor runner `advisor_consult.py`, which picks a BIO from `advisor_bios.json`. Chain: `claude -p` read-only (Read/Grep/Glob only, no MCP, recursion guard) → Codex read-only across the accounts `.codex-3` → `.codex-2` → `.codex` → deterministic default.
- Plan approval goes to a plan-reviewer advisor, at most 2 revisions, and only when the agent itself entered plan mode.
- A question at the end of a turn is answered at Stop.
- Hard owner boundaries (live orders, secrets, prod data deletion, payments, external messages) are **deferred without waiting**. They go to `~/.claude/state/question_router/owner_queue.jsonl` plus a notification, and the agent prepares «Готово, нажмите X». This was the owner's choice in this session.
- Manual mode is unchanged.

  - the session summary is per project.
