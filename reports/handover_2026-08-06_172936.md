GitHub MCP `403` was a separate authorization failure; disabling that remote

was removed from `~/.zshrc`; a new interactive shell now resolves `codex` to
`/opt/homebrew/bin/codex` version `0.146.1`. The launcher itself also rejects
the obsolete patch on version mismatch and falls back to the official binary.

not migrated by a newer binary or configuration. Start a new session with
plain `codex` after sourcing `~/.zshrc` or opening a new terminal.
