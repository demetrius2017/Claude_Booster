## Problems / Solutions

- Historical scorer could only choose models already sampled; discovery now admits
  same-class candidates independently of those samples.
- Claude Agent schema accepts aliases only: persist exact tier env mappings, and
  reject stale inherited mappings for verified routes with a restart diagnostic.
- Invalid receipts could change alias settings despite route rejection: one shared
  valid_receipt predicate now guards both boundaries; obsolete evidence requalifies.
- Model answers may use a JSON fence or equivalent slice expression: qualification
  accepts a bounded JSON envelope and explicitly correct expressions, without relaxing
  file nonce or arithmetic validation.
- Hooks are asynchronous: running workers remain unchanged; next launches see new
  routes. Claude sessions created before env changes need restart.
- Incident context sources were reviewed for relevant boundaries: never git-clean
  untracked artifacts; no cross-project data/runtime mutation; preserve snapshots and
  distinguish a successful probe from full service recovery. Old Horizon/AINEWS
  incidents are context, not current incidents in Booster.
