# Handover — 2026-07-31 15:51 MSK

## Summary

Added and shipped a canonical identity contract for Fable subagents. Every
Booster call through `fable_consult.sh` now sends the exact shared identity
preamble first, followed by one blank line and the caller task. Missing identity
data fails closed before Claude CLI is invoked.

Direct `Agent`/Workflow launches are covered by the new `fable-identity` helper
skill. The Codex bridge now distinguishes helper skills from command aliases,
so `fable-identity` installs without requiring a fictitious command spec.

The source change, installed Claude artifacts, installed Codex skill, and bridge
manifest were verified. Commit `351da06` was pushed to `origin/main`.

Residual risk: deterministic wrapper calls are enforced in code, while a raw
future `Agent(model="fable")` call still depends on the helper skill being
loaded and followed; there is no universal Agent prompt-rewrite hook. A future
new Fable launch path is therefore the principal falsifier and must either use
the wrapper or explicitly load `fable-identity`.
