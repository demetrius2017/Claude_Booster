2. **Weekly limit: there is no bug.** Claude Code 2.1.316 sends `rate_limits.seven_day` and it renders (`7d: 60%`). Dmitry confirmed he simply hadn't noticed it next to the long Fable line. Per-model weekly windows (`model_scoped`, `weekly_scoped`) are **not passed** to the statusline JSON by CC at all; they are visible only in `/usage`. This was verified by reading the `cDr` builder code in the binary `~/.local/share/claude/versions/2.1.316`.
