the user's arguments. Do not load the general Booster command runner.
In a source checkout where that installed reference is absent, read
`../../../commands/role.md` relative to this skill directory instead.

The new-session default is supplied by the small optional
`references/session-defaults.md` snippet in the user's global Codex instructions.
The snippet is installed there explicitly; it is not an automatic hook.
